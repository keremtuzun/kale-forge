# Kale Forge Design Model — adapter v4

**What it is:** a LoRA adapter that specializes `mlx-community/Qwen3-4B-Instruct-2507-4bit`
into the Design Studio's FRC design-intent task (team request → one schema-valid design intent
JSON). This is the product's design adapter — **not** the robotics-synthesis foundation model in
[docs/robotics-synthesis-roadmap.md](../docs/robotics-synthesis-roadmap.md).

## Training

| | |
|---|---|
| Base model | `mlx-community/Qwen3-4B-Instruct-2507-4bit` |
| Method | LoRA (MLX), 6 layers, rank 8, scale 20 |
| Trainable params | 2.75M (0.068% of 4.0B) |
| Dataset | `datasets/processed/design-v4` — 2,298 rows (1,838 train / 230 val / 230 test) |
| Corpus mix | 1,400 `design_intent` · 320 electrical · 58 parts_qa · 28 technique · 12 diagnosis · 480 merged general-design |
| Iters / batch / LR | 300 · 1 (×4 grad-accum) · 1e-4 |
| Seq length / mask_prompt | 2048 · true |
| Final loss | **train 0.073, val 0.061** (from val 3.561 at iter 1) |

Config: `training/configs/mlx-design-4b-v4.yaml`. Data generated by
`kale_training.generate_frc_corpus` (`--intent-count 1400 --electrical-count 320 --seed 4242
--merge datasets/processed/design-v2`) — derived from Kale's own catalog, license `internal`.

## Behavioral evaluation (6 held-out diverse prompts)

Ran the adapter and the base model on deliberately varied prompts (not verbatim in the corpus).

| Metric | Fine-tuned v4 | Base Qwen3-4B |
|---|---|---|
| Valid design JSON | 6/6 | 6/6 (mostly `None` fields) |
| Distinct designs | **6/6** | 2/6 |
| Exact copies of a training row | **0/6** | 0/6 |
| Mean similarity to nearest training row | 0.945 | 0.065 |

Decisions track constraints: defense → west-coast drive; "no shooter"/"no climber" honored;
rookie/tight-budget → swerve-ready + simpler mechanisms.

## Honest limitations

- **Template-bounded prose.** `design_notes`/`risks` reproduce the corpus's templated phrasing,
  so nearest-row string similarity is high (0.945 mean, 0.996 for a very standard request). It
  does not copy whole designs (0 exact matches; engineering decisions vary per prompt) but it is
  not yet freely inventive in language or mechanism.
- **Scope.** Produces a design *intent* (subsystem/architecture choices), not native editable CAD.
- Never claims rule compliance, structural safety, or fabrication readiness.
- Free-form novelty is the roadmap's frontier (bigger legally-sourced corpus + novelty objective).
