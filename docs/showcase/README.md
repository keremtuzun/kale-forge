# v15 design showcase — 2026-07-30

Ten complete robot specs generated live by the `kale-design-qwen3-4b-v15` adapter
(5 per season, 28–76 s each, `model.used: true` on every one). Prompts deliberately
include mechanisms held out of CAD training, an illegal 28×28 frame for 2026, and
rookie/defense/feeder archetypes. `v15-showcase-report.html` is the readable report.

Every spec is full Design Studio output: subsystems, CAD tree, power budget, mass
roll-up, rule check, and dossier fields. Concept geometry — do not machine from it.
